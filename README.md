# 广东美食之旅

可交互的广东美食地图，包含 21 家餐厅，其中 20 家已定位，1 家地址待确认，另有广州白云国际机场和合肥新桥国际机场的蓝色飞机标记，以及合肥空港大酒店（新桥国际机场店）和佛山顺德欢乐海岸欢乐大道亚朵酒店的紫色酒店标记。

另有珠海长隆海洋王国的青绿色景点标记，以及珠海横琴希尔顿逸林酒店和横琴凯悦酒店的紫色酒店标记，可查看简介、开放或入住退房时间、官方资料与导航。

支持地图拖动与缩放、餐厅详情、营业时间、多个用餐标签、美食图片和店铺导航。

顶部“美食与行程地图”和“长隆游玩攻略”采用两个可点击切换的页签，一次显示一个页面，切换保留地图选择、缩放和清单勾选状态。支持键盘左右键、浏览器前进后退，以及直达攻略段落的链接；从攻略首次切回地图时再初始化地图尺寸。

页面包含 2026 年 9 月 19 日两位成人的珠海长隆海洋王国一日游攻略：官方园区地图、建议时间线、项目维护与夜场提醒、行前清单、自驾和住宿衔接。园区导览图直接引用长隆官网，在展开时才联网载入，支持缩放和滚动；加载失败不会影响行程文字或原有地图。官方资料核对于 2026 年 9 月 14 日，演出等信息须在出行当天复核。

`index.html` 内嵌地图概览、全部地点、样式、脚本与解压库，不等待 DOMContentLoaded 即可启动。街道细节保存在 `assets/maps/`，每个文件不超过128KB，按需分批下载；单次请求12秒超时后可重试，概览和地点仍可操作。食物图片保存在 `assets/`，点击餐厅后按需加载。使用 GitHub Pages 从 `main` 分支根目录发布；`.nojekyll` 让 Pages 直接托管静态文件。

## 内容说明

营业时间依据公开资料整理，以店家最新公布为准。未核实的位置或营业时间已在页面中标注。
参考菜品图片与本店实拍分开标明，作者、来源和许可见各图片说明；AI 生成图片另有标注。

更新网站时，将生成的 `index.html` 与配套 `assets/` 一同提交到 `main` 分支。可下载的单文件版本包含美食图片及行程底图，支持离线打开；长隆官方园区导览图需联网查看。
