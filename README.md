# 广东美食之旅

可交互的广东美食地图，包含 21 家餐厅，其中 20 家已定位，1 家地址待确认，另有广州白云国际机场和合肥新桥国际机场的蓝色飞机标记，以及合肥空港大酒店（新桥国际机场店）、佛山顺德泷居酒店、佛山顺德美的万豪酒店、佛山顺德欢乐海岸欢乐大道亚朵酒店和丽枫酒店（惠来隆江镇政府店）的紫色酒店标记。

另有珠海长隆海洋王国的青绿色景点标记，以及珠海横琴希尔顿逸林酒店和横琴凯悦酒店的紫色酒店标记，可查看简介、开放或入住退房时间、官方资料与导航。

支持地图拖动与缩放、餐厅详情、营业时间、多个用餐标签、美食图片和店铺导航。

`index.html` 内嵌地图概览、全部地点、样式、脚本与解压库，不等待 DOMContentLoaded 即可启动。街道细节保存在 `assets/maps/`，每个文件不超过128KB，按需分批下载；单次请求12秒超时后可重试，概览和地点仍可操作。食物图片保存在 `assets/`，点击餐厅后按需加载。使用 GitHub Pages 从 `main` 分支根目录发布；`.nojekyll` 让 Pages 直接托管静态文件。

## 内容说明

营业时间依据公开资料整理，以店家最新公布为准。未核实的位置或营业时间已在页面中标注。
参考菜品图片与本店实拍分开标明，作者、来源和许可见各图片说明；AI 生成图片另有标注。

更新网站时，将生成的 `index.html` 与配套 `assets/` 一同提交到 `main` 分支。可下载的单文件版本仍包含全部图片，支持离线打开。
