# 广东美食之旅

可交互的广东美食地图，包含 21 家餐厅，其中 20 家已定位，1 家地址待确认。

支持地图拖动与缩放、餐厅详情、营业时间、多个用餐标签、美食图片和店铺导航。

`index.html` 内嵌地图、样式、脚本和图片，使用 GitHub Pages 从 `main` 分支根目录发布；`.nojekyll` 让 Pages 直接托管静态文件。

## 内容说明

营业时间依据公开资料整理，以店家最新公布为准。未核实的位置或营业时间已在页面中标注。
参考菜品图片与本店实拍分开标明，作者、来源和许可见各图片说明；AI 生成图片另有标注。

更新网站时，用新版完整 HTML 替换 `index.html` 并提交到 `main` 分支即可。
